# 📰 AI 뉴스 앱 - MyNewsAI

뉴스를 보고, 검색하고, 마음에 드는 기사를 저장하고, AI로 요약까지 해볼 수 있는 간단한 뉴스 앱입니다.


## 📅 개발 기간
* 26.04.02 - 26.04.17 (약 3주)


## 📱 주요 기능

* 뉴스 목록 : 다양한 카테고리의 최신 뉴스를 조회합니다.
* 키워드 검색 : 검색 기능을 통해 원하는 주제의 기사를 찾습니다.
* 북마크 : 관심 있는 기사는 저장하고 관리합니다.
* AI 요약 : 뉴스 상세 화면에서 뉴스의 핵심 내용을 AI로 제공합니다.


## 🛠 사용한 기술

* Kotlin
* Jetpack Compose
* MVVM
* Retrofit2, OkHttp
* Room Database 
* Paging3
* Hilt
* Coil
* Gemini API
