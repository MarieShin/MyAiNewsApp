# 📰 AI 뉴스 앱 - MyNewsAI

뉴스 조회, 검색, 북마크 기능과 AI 요약 기능을 제공하는 안드로이드 뉴스 앱입니다.

<br>

## 📅 개발 기간
* 26.04.02 - 26.04.17 (약 3주)

<br>

## 📱 주요 기능

* 뉴스 목록 : 다양한 카테고리의 최신 뉴스를 제공합니다.
* 키워드 검색 : 원하는 키워드로 뉴스를 검색할 수 있습니다.
* 북마크 : 관심 있는 기사를 저장하고 관리할 수 있습니다.
* AI 요약 : Gemini API를 활용해 뉴스 핵심 내용을 요약합니다.

<br>

## 🛠 사용한 기술

* Kotlin
* Jetpack Compose
* MVVM
* Retrofit2, OkHttp
* Room Database 
* Paging3
* Hilt
* Coil
* Gemini API

<br>

## 💡 기술적 고민

### Paging3 적용
* 뉴스 데이터를 효율적으로 불러오기 위해 Paging3를 적용했습니다.
초기 로딩 부담을 줄이고 스크롤 성능을 개선했습니다.
